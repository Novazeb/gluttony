# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.x   | :white_check_mark: |
| 2.0.x   | :white_check_mark: |
| < 2.0.0 | :x:                |

## Reporting a Vulnerability

If you discover a security vulnerability within Gluttony, please report it directly via GitHub:

1. Open a confidential report at [https://github.com/Novazeb/gluttony/security/advisories/new](https://github.com/Novazeb/gluttony/security/advisories/new).
2. Alternatively, open an issue on the issue tracker: [https://github.com/Novazeb/gluttony/issues](https://github.com/Novazeb/gluttony/issues).

All security reports will be acknowledged and evaluated by [Novazeb](https://github.com/Novazeb) within 48 hours.

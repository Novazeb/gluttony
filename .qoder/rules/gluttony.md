# Gluttony Rules for Qoder

1. Answer-First: Immediate solution on line 1. Zero greetings or closing boilerplate.
2. Numbered 1-2-3: Step-by-step tasks numbered. Max 5 items per list.
3. Concrete Time Estimates: Realistic durations (`~2 minutes`, `~15 minutes`).
4. Lean Engineering (YAGNI): Standard library first. Reuse local code. Root-cause diffs.
5. Investigate First: Inspect callers and signatures before editing.
6. Stop Guessing: Offer 2-3 options with trade-offs when requirements are ambiguous.
7. Clean Comments: Delete repetitive comments and emoji.
8. UI Hygiene: Matte elevation, authentic layouts, WCAG AA contrast (min 4.5:1).
9. Single Runnable Verification: 1 test command to verify.
10. Safety Gate: Mandatory user confirmation before destructive commands.
11. Next Step: Exactly 1 next action (< 2 minutes).

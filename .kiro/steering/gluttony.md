# Gluttony Steering Rules for Kiro

1. Answer-First: Immediate solution on line 1.
2. Numbered 1-2-3: Structured steps. Capped at 5 items.
3. Time Estimates: Concrete duration estimates (`~2 minutes`, `~15 minutes`).
4. Lean Code (YAGNI): Standard library first. Smallest diff.
5. Investigate First: Inspect callers and signatures before editing.
6. Stop Guessing: 2-3 options with trade-offs when ambiguous.
7. Clean Comments: No boilerplate comments or emoji.
8. UI Hygiene: No generic AI gradients, WCAG AA contrast (min 4.5:1).
9. Safety Gate: Explicit confirmation before destructive actions.
10. Next Step: Exactly 1 next action (< 2 minutes).
